# 异世界公会长 Godot 客户端

Windows 64 位客户端。打开 `GuildMaster.exe`，可连接原服务器，也可进行离线单人挑战。无需安装 Godot、Python 或 Ren'Py。

2026-10-15 卡牌修复：A-077「極彩爆裂砲彈」第一效果按卡面选择自己支配区域相邻的非魔王迷宫，不再错误要求邻接据点。替换不消耗或要求可用冒险者；没有可用冒险者时仍能替换为空白板块，后续探索按正常条件自动跳过。有可用冒险者时仍可选择探索或跳过。离线已内置修复；联机房间需同步更新服务器包。

2026-10-15 连接修复：空房间大厅也会正常切换显示，连接成功只在服务器确认后提示；握手15秒无响应会提示同步超时。全部玩家断线后的房间按原重连宽限清理，观战者不会阻止销毁，房间销毁后自动返回大厅。需部署本次服务器包才能启用服务器清理修复。

开房及房间规则新增自定义初始文明（1–1000）与瘴气（0–1000）。不勾选时使用原来按人数、扩充、单人难度确定的初始值；自定义只影响开局，后续增减与终局仍按原规则。联机使用这一选项需要同步更新服务器包。

程序、窗口与任务栏图标使用游戏中海涅的原立绘头像；Windows 图标包含 16 至 256 像素的七档尺寸。

主菜单「异世界」改为浅金色，「公会长」和介绍改为暖白色，补充说明与页脚使用浅米色；标题增加轻阴影，保持原背景和排版。

卡牌标题统一使用深酒红色，提高纸面背景上的对比度，文字位置沿用原卡。

默认帧率上限为 240 FPS，垂直同步默认关闭；偏好设置可选择 60、120、144、240 或不限帧率，也可开启垂直同步。实际帧率取决于硬件及场景，垂直同步开启后也受显示器刷新率限制。动画背景改用着色器，静态地图与字体卡面在内容或尺寸变化时绘制并缓存，保留原布局、鼠标交互、Alt 放大和动态高亮；缓存仅在运行时存在，不增加文字图集文件。

创建房间和房间规则的角色候选张数改为下拉选项。按最大玩家数和禁用角色核对可用角色池，候选不足时自动调整到可用上限并提示；每位玩家至少有一名候选才允许提交。最终阶段提示的三行文字、六秒自动消失、剩余行动次数与 Ren’Py 一致；结算时关闭旧行动面板，显示原声望分项和单人胜负提示。

2026-10-14 最新更新：断线玩家卡片覆盖灰色遮罩，闭店覆盖红色遮罩；两种状态可同时叠加，状态文字保持清楚可见。重连移除灰色遮罩，下一季移除红色遮罩。卡牌沿用原来的底纹、边框、符号及布局，卡名、费用和已核对的效果文字使用思源黑体按原文字框现场绘制。原卡底部的细小背景故事和未核对文字保留在底图内，以免自动识别改变内容。板块保留原符号组件，角色及场景插画保留原图。

选牌更新：选中的卡牌和板块覆盖半透明遮罩，中央显示「已选择」。轮抽、情报收集及结算选牌在选择、取消和同一牌组刷新时保留滚动位置，下一牌组从顶部开始。顶栏文明与瘴气之间新增进度条，显示还差多少文明，按原规则「文明 +1 ≥ 瘴气」判断达标。

地图顶部常驻五种宝物图标，已领取的宝物变灰；点击查看每件的具体奖励和归属。顶栏「离开」右侧显示尚未领取的文明 / 瘴气旗标门槛及声望 +1 图标；未开启旗标奖励时显示未开启，公会委托扩展则标为贡献 +1。玩家面板收紧底部留白，所有人数均保留头像、资源、断线状态与冒险者计数。连续结算步骤由原引擎驱动，下一步需要选择时自动弹窗，最后一步完成后自动关闭。

2026-10-14 更新：修复离线准备、选角和对局的离开房间；联机退出返回大厅，断线退出清除重连席位，大厅退出返回主菜单。鼠标悬停不再自动弹图，按住 Alt 才显示大图，松开收起。宝箱选项显示原资源符号和具体奖励，知识宝物列明生活、商业、零件标记。地图显示各玩家原冒险者碎片及据点图案。压缩公会资源区，增大六个秘药行动按钮。删除背景音乐和音乐设置，保留操作音效。

桌面采用与当前 Ren’Py 客户端相同的 1920×1080 坐标系。顶栏六个入口、右侧两排行动按钮、王权入口、日志按钮，以及主菜单、房间准备、候选角色、轮抽、情报收集、九张手牌翻页及主要操作窗口沿用原排列和入口。UI 保留暖纸色风格，卡面仍实时合成。

「我的板块」打开同一板块收藏；「特殊能力 / 扩展」直接进入与 Ren’Py 一样的单层入口；基本药与炼金药按规则分开，霍伦可用板块替代秘药。发展资格、庆典分配、力量折抵及探索支付上限与 Ren’Py 原 helper 逐项比较，420 个输入结果一致。私人王权售卖按本局规则的 5 金币，闭店后仍可自由售卖；达到选择要求才允许提交结算。输入时通过原服务器计算和核验，没有客户端模拟另一套规则。本次已同步加入自定义初始文明/瘴气，游戏仍由同一规则引擎计算。

联机使用原服务器的四字节大端长度头 + UTF-8 JSON，游戏版本 3.2.0、协议 3；服务器包已加入自定义初始值、回放预览和胜率接口。离线模式随客户端携带原有规则模块与官方 Python 嵌入式运行库，通过仅监听本机的适配器调用原规则，不维护另一套结算规则。

界面参考用户另一项目「建筑经理」，使用暖纸色、深灰描边和低饱和红色，保留漫画纸面的斜切边框与标题字体。选角、轮抽、情报收集、发展、王权、秘药、委托、扩充行动和服务器结算选择均由 Godot 绘制。无立绘卡按原卡的背景和原坐标现场绘制主要文字；不更换原卡排版。地图板块按原版转 −30°。人物和场景插画保留原素材。

快捷键：

- 将鼠标移到卡片上，按住 **Alt** 查看大图；松开后收起。鼠标悬停不自动弹图。
- **Esc**：关闭普通面板或打开设置；必须完成的服务器结算不能用 Esc 跳过。
- **F11**：切换全屏。

设置控制操作音效、音效音量、动画与操作提示，保存在用户应用数据目录。Alt 在卡片悬浮时打开中央大图；松开收起，移出卡片后不会在空白处重新打开旧图。卡片、迷宫提示与漫画背景具有动画；动画可独立关闭。固定按钮仅改变悬浮色泽，不改变坐标或尺寸。

左侧五位玩家同时显示原角色立绘、资源、产能、好感、声望及玩家颜色对应的冒险者碎片标志和未使用数量。断线、倒计时和本季闭店独立显示，断线且闭店时两项都显示，长名字不会截断状态。地图资源栏下方直接显示秘药行动费用及可用、本轮已用、数量不足、未开放、等待行动状态，使用入口按服务器快照和当前行动权限启用。五人模式在默认和最小窗口均检查了显示边界。

引擎、Python 和素材许可证见 `LICENSES` 与 `runtime/LICENSE.txt`。

源项目 `project.godot` 可使用 Godot 4.7.2 打开。`tools/prepare_client.py` 读取原项目并复制所需资源；先运行 `tools/optimize_card_components.py` 准备原组件，再使用 `tools/prepare_native_ocr.py`、`tools/ocr_native_faces.ps1`、`tools/prepare_native_fonts.py` 和 `tools/activate_native_fonts.py` 生成并验证原布局字体卡面，最后运行 `tools/build_windows.py`。OCR 仅用于定位，文字采用已经核对的摘录；未核对的内容留在原底图。`tools/run_network_qa.py` 测试与原客户端混合联机；`tools/run_status_network_qa.py` 启动临时本地服务器测试断线、重连、闭店、遮罩和换季，结束后关闭服务器并核验端口释放。运行 `tools/prepare_treasure_fixture.py` 后，`tools/run_godot_qa.py` 验证界面、宝箱、Alt 和离线退出。QA 资料不进入运行包。

运行包的 `art` 文件夹保留需要的压缩插画、人物素材、原卡底图和板块符号组件。整包解压后运行，请保留 EXE 同目录下的 PCK、art、rules、runtime 和 LICENSES。

317 份原坐标布局中，274 份卡面采用原底图与现场字体，不携带旧卡牌文字图集；43 份地图板块保留原符号组件。字体大小根据实际显示尺寸调整，字形的可见边界对齐原文字框。原始图包、Ren'Py 和服务器素材保持不变。
