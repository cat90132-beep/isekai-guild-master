关于本作

一局游戏，经营一座跨世界公会

《异世界公会长》是一款完整实现中文规则书的中文策略桌游，使用 Ren’Py 制作，逻辑分辨率 1920×1080。你在迷雾笼罩的迷宫边缘开张公会：派人探索未知板块、用事件卡扩张产能、把资源投进发展与据点，最后凭声望与王权卡决出本季度最成功的公会长。

游戏提供 2–5 人联机、公开观战与不依赖服务器的离线单人挑战三种玩法。五人自动使用大地图；房主可以在开局前自由开关事件包、变动板块、炼金工房、潜行之龙、魔兽讨伐、庆典准备、行动倒计时等扩充规则。

服务器端自带 在线回放网站：每一局从开局到终局逐步落盘，可在浏览器里拖动进度条复盘，查看每个公会的手牌、板块、发展项目与计分明细。

玩法特色

从探索到结算的完整循环

迷雾迷宫与板块

六角迷宫由你亲手翻开。板块按星数决定探索代价，占领据点后能持续产出资源；深渊洞穴与禁止区域会打乱整条路线。

事件卡与三色标记

情报收集阶段用金币抢下情报，打出事件卡获得金币、力量、秘药与产能，并积累生活、商业、零件标记来满足更强卡牌的前置条件。

看板娘与黑白版本

每位公会长都有一名看板娘。好感度达到 2 / 5 时立即升级并解锁二级、三级效果；同一角色提供黑、白两种规则版本，玩法节奏完全不同。

王权卡与终局结算

公开与私人王权卡提供终局声望，部分卡牌还会按标记数量额外计分。文明与瘴气接近时进入终局，每人获得有限的最终行动。

联机、观战与重连

房主设置地图、事件包与扩充开关，所有人准备好后再抽取角色候选。断线可以临时令牌或原名重连；观战者只能看到公开内容。

扩充规则

大深度迷宫、大变动地图、变动板块、炼金工房、公会委托、故事之始、魔兽讨伐、潜行之龙、魔之森、庆典准备与行动倒计时，均可按局开关。
