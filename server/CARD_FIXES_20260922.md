# 卡牌核对修正 · 2026-09-22

## 第三次修正：投资炼金术公会

移除A-061多余的生活标记前置条件。无生活标记时，单人和多人均可支付15金币打出，获得1秘药、1秘药产能、抽1事件卡及1名声。新增实际出牌回归测试，全套188项测试通过。

## 第二次修正：赛莲与小幻兽

用户补充反馈的两处问题在首轮修正后仍存在，本次已复现并修复。

- 白版赛莲：首次行动前减20金币打出事件后，不再自动重放最初点击的主要行动，避免“手中没有这张事件卡”、同名卡被连续打出或额外扣费。完成／跳过初始能力后，由玩家重新选择主要行动。
- C-021 捡到小幻兽：特别行动可选1～2块持有板块放在卡上，每块获得1战力。板块仍计入持有数量、标签与名声，不能再用于支付。只有1块可用时选择上限为1。
- 新增5项回归测试，包括单人／多人、同名卡重复、选择另一张卡、跳过能力、放置1块／2块和非法选择数量。全套187项测试通过。

客户端与独立服务器均加载 `guild_content.py`，在当前卡面版本选择完成后统一加载 `guild_card_corrections.py`。没有再为单人和联机各维护一套卡牌数值。

已按核对记录修正事件卡的费用、资源、名声、阈值、可选支付和顺序；王权条件与售卖金额；看板娘初始资源、升级奖励、翻面方向与额外行动时机；两星委托和序章洞穴重选。已核准的事件标题及原文摘录保留原字，程序规则说明与原文摘录分别标注，不把 OCR 当原文。
