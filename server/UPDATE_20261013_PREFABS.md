# 2026-10-13 原版坐标的代码绘制卡面与启动修复

## Ren’Py 客户端最终修订

当前客户端沿用原 Ren’Py 工程、按钮布局、联机协议及规则修复。Ren’Py 显示入口使用 `images/card_render_components` 中的小型背景及透明原字形、图标图集，按原坐标实时组合；服务器继续使用原 `images/card_components` 及原坐标元数据，服务器源码和三个服务器压缩包保持原 SHA-256。

317 份卡面/板块在原尺寸验证：`100 × (1 − RGB 平均绝对误差 / 255)` 的最低结果为 97.1365%；透明轮廓、组件坐标逐字节一致。序章底纹保留较高分辨率的原版花纹。此数值是明确的像素误差指标，不代表全部扫描噪点完全相同。报告为 `qa/renpy-card-similarity.json`，对照图为 `qa/renpy-card-comparison.png`。

排除 279 个完整文字卡面/混合图包资源，共 63,482,444 字节；实时组件为 38,882,080 字节，坐标元数据为 3,097,415 字节，混合图包中唯一插画卡的无损裁切为 302,640 字节，卡面资源净减少 21,200,309 字节。开发原图及完整图包备份继续保留，发行包不携带被替代的整卡和旧组件副本。下文 278 个资源及 7.83 MiB 是此前高质量组件方案的历史记录。

左侧同时显示五名玩家的立绘、原版冒险者标志和可用碎片数量；断线和本季闭店可以同时显示，断线倒计时读取房间公开状态。公会资源下方的六个秘药快捷格显示“消耗秘药 = 获得资源/行动”，知识药另显示原版文明 +1 标志。建设及打出事件的免金币范围与额外费用可悬浮查看；快捷按钮及原秘药窗口共用可用状态判定，实际行动仍交由现有规则处理。

修复板块支付、地图选择及私密迷宫笔记仍直接读取已排除整图的三个显示分支，统一通过实时合成入口。保留原版板块旋转、Alt 放大、探索与支付流程。背景音乐使用魔王魂 / 森田交一的アコースティック01，可在设置单独关闭；音乐署名和原始来源随发行包 README.txt 提供。

使用 `tools/prepare_renpy_card_assets.py` 从保留原图重建并校验客户端组件，`tools/build_renpy_client.py --sdk <RenPy-8.5-SDK>` 在隐藏目录生成干净发行包，验证 ZIP、资源排除及服务器文件未变。图形测试先移除所有被替代原图，再验证全部 317 份布局、Alt、五人状态、秘药实际操作、板块支付显示、私密迷宫笔记及音乐设置；测试存档仍仅位于隐藏目录。

纯文字及图标卡面使用代码现场绘制。原版字形、图标、边框被拆成透明组件并装入图集；每个组件都有原图中的精确坐标。运行时先绘制去除文字的小型纸张背景，再逐项绘制图集中的字形和图标，沿用原字体、行距、标题、费用、规则和页脚的位置。手牌、选择窗口、悬浮放大、图鉴、王权、序章与迷宫板块均使用这个入口。有角色或场景插画的卡片，包括带插画的委托，保留插画版本。

完整图包备份位于 `backups/art-pack-20261013-before-prefabs.zip`，包含 images、gui 和图包元数据，共 577 个文件。压缩包内 ART_BACKUP.json 记录每个文件的尺寸和 SHA-256，备份完成时逐个读回校验。

317 个原版卡面及板块具备组件绘制数据。透明轮廓采用无损编码，并通过原坐标复合后逐像素校验；图集 RGB 使用高质量 WebP，纸张底纹缩小存储，因此不宣称全部纸张像素与扫描原图完全一致。整张原卡面仅保留在开发目录和备份中，从发行包排除；混合图包中仍被插画卡使用的图包会保留。

发行客户端排除 278 个完整资源，共 62,432,302 字节；组件图集及背景共 51,127,008 字节，坐标数据 3,097,415 字节，净减少 8,207,879 字节（约 7.83 MiB）。原始资源和完整图包备份保留。迷宫板块的边框也独立保留原版像素坐标，避免缩小背景时模糊边缘。

运行时入口位于 expansion_screens.rpy 与 card_layouts.rpy；guild_card_layouts.json 记录原坐标及图集裁切框。tools/prepare_card_components.py 制作组件，tools/verify_card_components.py 检查原坐标、透明轮廓并生成左右对照图。核对数据位于 qa/card-layout-verification-20261013.json。

测试存档及备份已移入 `.qa-runtime` 隐藏目录；视频工具的辅助依赖目录移至 `video_intro/.runtime`。Ren'Py 8.3 与 8.5 均跳过点开头目录，避免启动前递归扫描私人工具目录引起 PermissionError。后续 UI 测试固定使用 `.qa-runtime/saves`；临时客户端也只能创建在隐藏的 `.qa-runtime` 下。

服务器回放使用同一份原坐标数据，生成包含背景及图集裁切指令的 SVG，浏览器现场组合卡面；服务器无需 Pillow 或 Ren'Py。插画图片 URL 保留原有 JPEG/PNG。deployment/guild-server.zip、downloads/guild-server.zip 和 server.zip 同步为 hainie-initial-unlock 修订。
