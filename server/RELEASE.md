# 3.1 更新说明

2026-09-10，中文界面。客户端和服务器请同步更新。

## 修复

- 赛莲开局的浮空实验室：地图外缘显示可点击的亮边六角格；放置后的实验室在所有玩家的地图上可见。
- 免费出牌：按控制区域等数量计算的收益集中在同一个资源结算入口。正常与免费打出《钓饵》均按每个控制区域 +2 金币到账一次，保留薇伊明确支付双倍费用的特殊规则。
- 单人王权：使用专用六张王权图集，支持点击查看大图。
- 探索资源交付界面可卖实际持有的秘药，每枚换 3 金币，不消耗行动，不退出当前探索。

## 桌面与公开信息

- 地图、当前玩家标题居中；右侧常驻公共王权与行动按钮；手牌每页九张。玩家栏显示资源、产能、新版看板娘立绘和计时。
- 原有 22 个角色版本改用新版中文完整卡面，三个等级对应各自的图集区域。
- 补齐赛莲白版、梅莉莎白版、莎菲亚黑版（与露比配对）、皮耶利亚黑版的完整能力和三级卡面。现在 23 组角色均有黑白双版，共 46 个可选版本。
- 浮空实验室与迷宫板块使用相同旋转角度；金币、力量、秘药及三种产能使用公会板原图裁片。顶部恢复下季额外奖励和自己的预计收入，受丰收、公会委托、庆典、妖精女王及终局规则影响。
- 点击玩家查看公会总览，显示已解锁的好感度条件与选择的序章；「序章与好感度」可查看序章卡图和详细成长状态。
- 板块总览包含持有板块、人物卡附属板块、事件卡附属板块，任何玩家均可查看这些公开信息。
- 顶部显示本季起始玩家。对局中的设置按钮已移除，菜单页仍可调整设置。
- 王权议事厅的卡牌支持悬停后按 Alt 在屏幕中央查看大图；桌面的「我的板块」区域可直接容纳六块板块，更多板块可滚动查看。
- 公会总览同时显示当前金币、力量、秘药和对应的三项生产力；情报选择阶段可随时打开已有手牌。
- 聊天消息到达客户端后立即进入弹幕，多条同时到达时会分轨同时显示，不再按固定间隔排队。
- 左侧玩家栏的资源与生产力图标放大，并增加与资源种类对应的描边底框。

## 房间与等待时间

- 房主可在等待、选角及对局中踢出其他玩家；本人不能被该操作踢出。被踢玩家的重连令牌失效，同昵称不能重新加入这个房间。
- 对局中的离场席位保留地图及已取得的资源、声望；必要选择自动完成，其余时间自动闭店，避免对局被卡住。
- 「强制大地图」不再依赖玩家人数，一般地图 47 格、大深度 64 格。与训练地图同时选择时使用一般大地图；不能与禁止区域同时开启。
- 「开放所有人数的秘药行动」忽略人数带来的禁用格。炼金格仍需开启炼金工房模块。
- 「行动倒计时」默认关闭；开启后基础默认 30 秒、备用默认 120 秒，开局前可修改。
- 从正式进入对局开始计时。情报收集与行动均有基础时间；同一行动中的连续效果选择沿用剩余基础时间。基础用完才消耗备用；基础在新回合刷新，备用整个对局不刷新。查看卡牌或打开菜单不会暂停。
- 有计时的对局在断线时继续倒数；无计时仍按原有重连等待规则。时间耗尽后，跳过可选效果、自动完成必要选择，然后本季闭店。无法执行的结算步骤不发放收益。
- 服务端记录自动结算的每一个步骤；公开回放仍在 6767 端口，可拖动进度条切换步骤。手牌与未公开信息不进入公共回放。

## 验证方式

新增规则、计时、全部 46 个角色的开局超时、断线与回放、踢人权限测试见 `tests/test_v6.py`。实际 UI 测试见 `tests/ui_v6.rpy.test`，包括赛莲点击放置、探索卖药、王权图片、五人桌面、九张手牌、成长状态及免费出牌资源到账。

服务器为纯 Python 标准库程序；`deployment/guild-server.zip` 与根目录 `server.zip` 保持一致，包内 `BUILD_INFO.json` 含构建时间和文件校验值。
