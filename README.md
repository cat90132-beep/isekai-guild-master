# 異世界公會長 (Guild Master) - Godot 客戶端

基於 Godot 4 引擎重構的《異世界公會長》Windows 64 位元客戶端。  
內置官方 Python 原生規則引擎與完整遊戲圖資，支援 **線上聯機對戰**、**離線單人挑戰** 以及全新的 **本機客座多人模式**。免安裝 Python、Godot 或 Ren'Py 環境，解壓即可暢玩。

## 🌟 本次主要更新內容 (Changelog)

### 1. 🎴 卡牌卡面規則錯誤修正
* **嚴格核對官方原版卡面與效果**：修正多張事件卡、王權卡與角色能力的費用、門檻、標記與結算順序。

### 2. 🎨 全面更新美術圖檔

* **冒險者的慶典卡面更新**：擴充卡牌移植到台版卡片，維持卡片風格一致。

### 3. 🖼️ 卡面全面統一為實體掃描圖 (Scan-based Cards)
* **告別 OCR 殘字問題**：全數更換為官方實體卡牌高清掃描圖，徹底解決過往動態文字套版時發生的「框內殘字」、「外框殘留」以及「雙重印刷」的重疊顯示問題。
* 文字佈局、符號標註、背景小故事均與實體卡 100% 一致。

### 4. 🌐 新增繁體中文 (zh_TW) 語言支援
* 偏好設定中新增 **簡體中文 / 繁體中文** 一鍵即時切換功能，無需重啟遊戲。
* 繁體中文導入專屬字型（如「宇文天穹」）最佳化排版，解決缺字與跨平台顯示異常。

### 5. 🖥️ 全新 UI 與操作反饋最佳化
* **動態面板與操作體驗**：重構右側成就、秘藥、好感度、特殊行動、公會資源面板與行動按鍵佈局。
* **狀態遮罩與流暢選牌**：斷線（灰色遮罩）與閉店（紅色遮罩）狀態清晰獨立標註；輪抽、情報收集與結算選牌保留滾動記憶，不再強制回彈頂部。
* **高清預覽體驗**：更新手牌瀏覽按鈕永久顯示，可隨時開啟介面閱讀放大的卡面文字，並保留`Alt`展開高清大圖功能。
* **玩家詳細資料介面更新**：增添標籤數量、序章卡及獲得寶物數量顯示，讓玩家判斷更輕鬆。

## ⌨️ 快捷鍵一覽

| 快捷鍵 | 功能描述 |
| :--- | :--- |
| **Alt (按住)** | 滑鼠移至卡片或板塊時，按住可在畫面中央展開高清大圖，放開立即收合。 |
| **Esc** | 關閉當前對話面板 / 開啟偏好設置。（必須完成的結算步驟無法跳過） |
| **F11** | 切換視窗化 / 全螢幕模式。 |

## 🚀 執行與安裝說明

### 經過Godot編譯exe（exe檔過大無法上傳github，須將原始檔Export）
1. 至 Release 下載打包檔案並解壓縮。
2. 使用 Godot 4.7.2 開啟 GuildMaster-Godot-src/project.godot。
3. 點選功能表 Project -> Export...（專案已內置配置好的 export_presets.cfg）。
4. 點擊 Export Project 匯出為 GuildMaster.exe（與 GuildMaster.pck）。
5. 將產出的檔案與 art/、rules/、runtime/ 放在同目錄下即可直接運行。
6. 執行 `GuildMaster.exe` 即可開始遊戲。

### 若要在Godot中執行測試(按F5)
如果要在 Godot Editor 內直接按 F5 執行測試，請將 GuildMaster-Godot/ 裡面的 art、rules、runtime 資料夾複製（或建立軟連結）到 GuildMaster-Godot-src/ 底下即可。

### 開發者構建 (From Source)
* 本專案源碼使用 **Godot 4.7.2** 製作，可使用 Godot Editor 開啟 `GuildMaster-Godot-src/project.godot`。
* 構建工具與驗證腳本位於 `tools/` 目錄。
